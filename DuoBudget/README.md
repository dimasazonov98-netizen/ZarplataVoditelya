# DuoBudget 1.5.0

В 1.5.0 правила обязательных ежемесячных расходов входят в общий бюджет пары: оба участника видят название, сумму, счёт, плательщика, дату и настройку напоминания, могут редактировать, отключать и удалять правила. Установите обновление на оба телефона. Старые локальные правила автоматически отправляются в общий бюджет при подключении к сети. Синхронизация работает, пока приложение открыто и разблокировано.

Оба телефона могут учитывать наступивший платёж. Идентификатор правила и месяца одинаков на обоих устройствах; сервер применяет команды атомарно, поэтому повторные запросы и одновременное создание не дублируют платёж. Удалённые правила сохраняются как скрытые записи, чтобы старые команды без сети не восстановили их. Оплаченная история сохраняется.

Напоминание приходит за день до оплаты в 09:00 по местному времени, если на этом телефоне разрешены уведомления. Новая версия подписывается тем же постоянным выпускным сертификатом и устанавливается поверх прежней с сохранением данных.

## Сборка

JDK 17, Gradle 9.6.0, Android SDK 36; `gradle testDebugUnitTest lintRelease assembleRelease`. Выпускной APK подписывается приватным ключом вне репозитория. GitHub Actions проверяет приложение на API 26 и 35. Финансовые суммы хранятся целыми копейками, локальное хранилище и резервные копии зашифрованы.
