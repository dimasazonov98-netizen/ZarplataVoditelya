# DuoBudget 1.1.2

Нативное Android-приложение для личного и семейного бюджета. Android 8.0 и новее; Kotlin, Jetpack Compose, minSdk 26, targetSdk 36. Финансовые суммы хранятся целыми копейками.

## Возможности

Доход, расход, возврат, кэшбэк, перевод между счетами; свои счета и начальные остатки; календарный месяц и лимиты категорий; накопления и цели; поиск, фильтры, изменение, корзина; зашифрованная переносимая резервная копия; CSV за месяц; автоматическая светлая и тёмная темы; виджет добавления расхода.

Версия 1.1 получила тёплый ботанический фон, полупрозрачные стеклянные карточки, контрастную навигацию, плавающую кнопку добавления операций и плавные анимации.

Накопления и суммы в целях резервируют часть общего остатка. Переводы между счетами не меняют общий баланс. Отрицательный доступный остаток отображается честно. Редактировать операцию в общем бюджете может её автор.

## Данные и защита

Локальное хранилище AES-256-GCM с ключом Android Keystore, атомарная запись, отключённый системный backup. При повреждении хранилища приложение не удаляет исходный файл. Резервные копии защищаются отдельным паролем от 10 символов, PBKDF2-HMAC-SHA256 и AES-256-GCM; доступ к общему бюджету в копию не включается. Утраченному паролю нет восстановления.

При наличии защиты телефона используется биометрия либо системный PIN/пароль. `FLAG_SECURE` закрывает стандартные снимки экрана и обзор недавних приложений. Приложению нужен интернет только для добровольно включённой синхронизации.

## Два телефона

HTTPS API с SQLite, отдельными случайными ключами устройств и одноразовым приглашением на 24 часа. Повторные запросы не дублируют денежные операции; изменения без сети хранятся в очереди. Синхронизация работает, пока приложение открыто и разблокировано. Firebase, номер телефона и банковский вход не требуются.

Адрес API зафиксирован в `BuildConfig.CLOUD_URL`. Публичный адрес сервиса активирован; сам бюджет требует ключ устройства. Шифрование передачи не является сквозным: администратор сервиса технически может читать серверные данные. Приложение показывает согласие перед подключением.

## Установка и переход с беты

Финальный пакет: `com.duobudget.family`, версия 1.1.2, versionCode 10102. Выпускной APK подписывается постоянным приватным ключом вне репозитория. Бета 0.3 использовала утраченный временный ключ, поэтому финальная версия устанавливается рядом с бетой. Автоматического доступа к данным другой установленной программы нет. Не удаляйте бету, пока не перенесли необходимые сведения.

## Сборка и проверка

JDK 17, Gradle 9.6.0, Android SDK 36, Build Tools 36.0.0. `gradle testDebugUnitTest lintRelease assembleRelease` создаёт неподписанный выпускной APK. Подпишите его своим сохранённым выпускным ключом через Android apksigner. Не используйте тестовый ключ для выпуска.

`gradle connectedDebugAndroidTest` проверяет защищённое хранилище и полный пользовательский сценарий. GitHub Actions запускает проверки на API 26 и 35. Переменная `DUOBUDGET_TEST_KEYSTORE` применяется только для временной подписи debug в CI; обычная локальная debug-сборка использует стандартный ключ Android.

Источники опубликованы в ветке `duobudget-final-v1` без изменения основной ветки существующего проекта. Результаты конкретной финальной проверки приводятся в отчёте к APK.
