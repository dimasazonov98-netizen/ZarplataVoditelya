# Изменения

## 1.0.0 — 9 октября 2026

- Целочисленные копейки и точный ввод рублей с запятой или точкой.
- Переводы между счетами, возвраты, кэшбэк, редактируемые счета и остатки.
- Корректный общий баланс, резервирование накоплений, частичное пополнение целей и возврат денег при удалении цели.
- Атомарное зашифрованное хранилище; восстановление повреждённого хранилища без удаления исходных файлов.
- Переносимая резервная копия с паролем и экспорт CSV.
- Нативный интерфейс, выбор месяца, поиск, корзина и быстрый вход через виджет.
- API для двух телефонов вместо незаполненной Firebase-конфигурации; очередь команд, защита от повторов и одновременных изменений.
- Отдельный окончательный идентификатор пакета и выпускная подпись; база беты остаётся в её собственном пакете.
- Модульные, API и Android-проверки в автоматизированном процессе сборки.
