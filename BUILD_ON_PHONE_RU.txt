СБОРКА APK С ТЕЛЕФОНА

1. Откройте вкладку Actions в репозитории.
2. Выберите Build APK.
3. Нажмите Run workflow.
4. Дождитесь зелёной галочки.
5. Откройте завершённую сборку.
6. В разделе Artifacts скачайте ZarplataVoditelya-APK.
7. Распакуйте ZIP и установите app-debug.apk.

Android SDK на телефон не нужен: сборка выполняется на GitHub.
