ЗАРПЛАТА ВОДИТЕЛЯ — ANDROID

Приложение уже содержит текущую версию калькулятора зарплаты.
Оно работает офлайн и хранит данные через локальное хранилище WebView.

Текущие условия:
- до 3 т: 5200 ₽
- 3–4 т: 5500 ₽
- 4–5 т: 5800 ₽
- без грузчика: +1500 ₽
- баллон: +200 ₽/шт.
- стойка: +150 ₽/шт.
- второй рейс: +4000 ₽
- пробег 180+: до 3 т +1500 ₽; 3–5 т +1700 ₽
- пробег 400+: до 3 т +2200 ₽; 3–5 т +2500 ₽
- ожидание удалено
- колонка «Грузчик» не используется

СБОРКА APK В ANDROID STUDIO:
1. Откройте папку проекта ZarplataVoditelyaAndroid в Android Studio.
2. Дождитесь Gradle Sync.
3. Меню Build → Build Bundle(s) / APK(s) → Build APK(s).
4. Готовый APK будет в app/build/outputs/apk/debug/app-debug.apk.

Для публикации в Google Play потребуется отдельная release-подпись.
