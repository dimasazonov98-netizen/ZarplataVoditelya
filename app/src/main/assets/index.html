Доплаты и правила
Флажок — разовая доплата, количество — сумма за каждую единицу, пробег — автоматическая доплата от указанного километража.
Для правил по пробегу применяется только самое высокое подходящее правило. Так доплаты 180+ и 400+ не складываются между собой.
